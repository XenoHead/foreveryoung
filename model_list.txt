OTHER:

**Image Generation & Vision**

* **`flux`, `flux-1-schnell`, `flux-2-dev`, `flux-2-klein-4b`, `flux-2-klein-9b**`: High-quality text-to-image generation models from Black Forest Labs. `schnell` is tuned for fast 4-step generation.
* **`stable-diffusion-xl-base-1.0` / `stable-diffusion-xl-lightning**`: Standard text-to-image latent diffusion models.
* **`stable-diffusion-v1-5-inpainting`**: Specialized for image editing, erasing background elements, and filling masked regions.
* **`dreamshaper-8-lcm`**: Latent Consistency Model tuned for photorealistic or stylized image generation with low step counts.
* **`resnet-50`**: Computer vision model for image classification and feature extraction.

**Audio Processing & Speech**

* **`whisper`, `whisper-large-v3-turbo`, `whisper-tiny-en**`: OpenAI Speech-to-Text models for transcribing spoken audio into written text.
* **`aura-1`, `aura-2-en`, `aura-2-es**`: Text-to-Speech (TTS) models powered by Deepgram for converting written text into natural-sounding voice output.
* **`melotts`**: Fast, lightweight Text-to-Speech synthesis engine.
* **`smart-turn-v2`**: Audio utility for detecting conversational turns and voice activity in real-time speech streams.

**Text Embeddings & Vector Search (RAG)**

* **`bge-base-en-v1.5`, `bge-large-en-v1.5`, `bge-small-en-v1.5`, `bge-m3**`: Vector embedding models used to turn text chunks into numbers for semantic search, document retrieval, and RAG databases.
* **`bge-reranker-base`**: Re-ranking model used after vector searches to score and sort retrieved context chunks by relevance.
* **`embeddinggemma-300m`**, `qwen3-embedding-0.6b`, `plamo-embedding-1b`: Text embedding models optimized for different parameter sizes and languages.

**Safety, Translation & Sentiment**

* **`llama-guard-3-8b`**: Safety classification model meant to screen prompts and outputs for harmful content, policy violations, or unsafe text.
* **`distilbert-sst-2-int8`**: Fast sentiment analysis model (labels text positive/negative).
* **`indictrans2-en-indic-1b`** / **`m2m100-1.2b`**: Multilingual translation models designed specifically to convert text between spoken languages without text generation.

**Niche & Specialized Utilities**

* **`moondream3.1-9B-A2B`**: Extremely small vision-language model used for image captioning and basic visual Q&A.
* **`llava-1.5-7b-hf`**: Multimodal model that accepts an image + text prompt to describe visual input.
* **`lucid-origin`, `nova-3`, `phoenix-1.0**`: Experimental, domain-specific background micro-models (often used for task routing, telemetry, or specific Cloudflare pipeline experiments).
